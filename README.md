## Create a course selling app

- Initialize a new Node.js project
- Add Express and jsonwebtoken as dependencies
- Create `index.js`
- Add route skeletons for user login, signup, purchase a course, and see course
- Add routes for admin login, admin signup, create a course, delete a course, and add course content
- Add middlewares for user and admin authentication
- Add a database (MongoDB), use dotenv to store the database connection string
- Define the schema for User, Admin, Course, Purchase
- Complete the routes for user login, signup, purchase a course, and see course
